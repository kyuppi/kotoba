# ことばルーム（サーバー契約・Firebase設定なし版）

## これは何？
入力した文字を同じ部屋の参加者へリアルタイムで共有するWebアプリです。
音声通話ではなく、文字による会話です。

## 使い方
1. HTTPSで公開したサイトを開く
2. ニックネームを入力して「新しい部屋を作る」
3. 画面に出た部屋コードを友達に共有
4. 友達は同じサイトでニックネームと部屋コードを入力して参加
5. 入力欄に文字を打つと、ほかの参加者の画面に表示されます

## 公開方法（GitHub Pagesの例）
1. GitHubにログインし、新しいPublicリポジトリを作る
2. `index.html`、`style.css`、`app.js` の3ファイルをアップロード
3. Settings → Pages → Deploy from a branch → `main` / `/root` を選択してSave
4. 数分後に表示されるURLを開く

## 技術について
- HTML / CSS / JavaScript
- PeerJSを利用したP2P通信
- Firebaseプロジェクトや自分専用サーバーは不要
- PeerJSの公開シグナリングサービスを接続確立に利用します

## 大事な制限
- 部屋を作った人の端末・ブラウザがオンラインである間だけ部屋を使えます。作成者が退出・ブラウザ終了・通信切断すると部屋は終了します。
- 部屋コードはPeerJSのピアIDです。一般的な6桁コードではなく、長い英数字になる場合があります。
- 参加者同士の通信はP2Pです。学校や公共Wi-Fiなどのネットワーク制限で接続できない場合があります。
- 公開シグナリングサービスの提供状況や利用条件は変わる場合があります。サービスとして長期運用する場合は、自分で管理するシグナリングサーバー等を用意してください。
- 部屋コードを知らない人に共有しないでください。個人情報・パスワードは入力しないでください。
- 本番利用前に複数端末・複数ブラウザで接続テストをしてください。

# ことばルーム（接続先明示版）

前のZIPからPeerJS接続設定を明示し、接続エラーの種類を画面と開発者コンソールに出すようにした版です。

## 公開方法
GitHub PagesなどHTTPS対応の静的ホスティングに `index.html`、`style.css`、`app.js` をアップロードしてください。

## 使い方
1. ニックネームを入力して「新しい部屋を作る」
2. 発行されたPeerJSの部屋コードを友達に共有
3. 友達は部屋コードを入力して参加
4. 入力欄に文字を打つと相手の画面にリアルタイム表示

## 通信について
PeerJS Cloud（0.peerjs.com）のシグナリングサービスで接続を仲介し、その後はWebRTCで端末間通信します。Firebaseは不要です。

## 注意
- 部屋の作成者がオンラインでいる間だけ部屋を使えます。
- 学校・会社・公共Wi-FiなどでWebSocketやWebRTC通信が制限されている場合は接続できないことがあります。
- PeerJS Cloudの稼働状況は変わる可能性があります。
- 個人情報やパスワードは入力しないでください。
